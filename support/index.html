官方 API 需要自行申請

HydroGuard 不提供、代管或共用政府 API 憑證。部分即時功能需要你先向資料來源平台申請，再到 App 的「API 設定」輸入。

中央氣象署

申請氣象資料開放平臺授權碼，用於天氣、雨量、預報及警特報資料。

查看官方申請說明

經濟部水利署

依水資源物聯網入口網說明申請 API 認證 ID 與密碼，用於受保護的水情資料。

查看官方 API 手冊

沒有 API 憑證可以使用嗎？

可以。你仍可查看 App 內附資料、本機快取及部分不需授權的資訊；需要認證的最新資料可能無法載入。實際可用範圍取決於官方服務、帳號權限與網路狀況。

定位沒有資料

  1. 到 iOS「設定」確認 HydroGuard 的定位權限為「使用 App 期間」。
  2. 回到 App 後重新按目前位置或重新整理。
  3. 仍無法定位時，可改用手動選擇縣市與行政區。
  4. 定位成功但測站沒有數值，可能是官方資料尚未更新或該區附近沒有對應設施。

HydroGuard 不會在背景持續追蹤你的移動路徑。

相機、相簿或 QR Code 無法使用

到 iOS「設定」中檢查 HydroGuard 的相機與照片權限。QR Code 只用來在裝置上讀取你選擇的 API 設定內容，不會自動送出或公開憑證。

如何清除 API 憑證

請在 App 的 API 設定中清除水利署認證資料與中央氣象署授權碼。建議先在 App 內清除，再移除 App，因為部分安全儲存項目的保留行為受 iOS Keychain 規則影響。

災情回報會直接送到政府嗎？

不會。HydroGuard 目前建立的是保存在裝置上的回報草稿，只有你使用 iOS 系統分享面板並確認後，內容才會交給你選擇的 App 或服務。遇到立即危險時，請直接撥打 119 或 110，並以政府公告與現場指揮為準。

Can I use the App without API credentials?

Yes. Bundled data, local caches, and some unprotected information remain available. Features that require authorization may not load the latest data. Availability depends on the official service, account permissions, and network conditions.

Location does not return data

  1. In iOS Settings, allow HydroGuard to use location while using the App.
  2. Return to the App and try Current Location or refresh again.
  3. If location remains unavailable, select a county and district manually.
  4. If location works but no reading appears, the official source may be delayed or no matching facility may be nearby.

HydroGuard does not continuously track your route in the background.

Camera, photo library, or QR code access does not work

Check HydroGuard camera and photo permissions in iOS Settings. QR codes are read on your device only to fill the API settings you select. Credentials are not automatically submitted or published.

How to clear API credentials

Clear the WRA credentials and CWA authorization key in API Settings. Clear them inside the App before uninstalling because some secure-storage behavior is controlled by iOS Keychain rules.

Are incident reports sent directly to the government?

No. HydroGuard currently creates local drafts. Content leaves the App only after you confirm sharing through the iOS share sheet and choose a destination. For immediate danger, call 119 or 110 and follow official notices and on-site instructions.

API 認証情報がなくても使えますか？

はい。App 同梱データ、ローカルキャッシュ、一部の認証不要情報は利用できます。認証が必要な機能では最新データを取得できない場合があります。利用可否は公式サービス、アカウント権限、通信状況によって変わります。

位置情報を使ってもデータが表示されない

  1. iOS の「設定」で HydroGuard の位置情報を「App の使用中」に設定します。
  2. App に戻り、現在地または更新をもう一度実行します。
  3. 位置情報を取得できない場合は、県市と行政区を手動で選択します。
  4. 位置情報が取得できても値がない場合、公式データの遅延や周辺施設がない可能性があります。

HydroGuard はバックグラウンドで移動経路を継続追跡しません。

カメラ、写真、QR コードが使えない

iOS の「設定」で HydroGuard のカメラと写真の権限を確認してください。QR コードは、選択した API 設定を端末内で読み取るためだけに使います。認証情報を自動送信または公開することはありません。

API 認証情報を削除する

App の「API 設定」で WRA 認証情報と CWA 認証キーを消去してください。安全な保存項目の一部は iOS Keychain の規則に従うため、App を削除する前に App 内で消去することを推奨します。

災害報告は政府へ直接送信されますか？

いいえ。HydroGuard は現在、端末内の下書きを作成します。iOS 共有シートで利用者が送信先を選び、確認した場合だけ内容が App の外へ渡ります。直ちに危険がある場合は 119 または 110 に連絡し、公式発表と現場の指示に従ってください。

공식 API 안내서 열기

API 인증 정보 없이 사용할 수 있나요?

네. App에 포함된 데이터, 로컬 캐시 및 일부 인증이 필요 없는 정보는 계속 사용할 수 있습니다. 인증이 필요한 기능은 최신 데이터를 불러오지 못할 수 있습니다. 사용 가능 범위는 공식 서비스, 계정 권한 및 네트워크 상태에 따라 달라집니다.

현재 위치에서 데이터가 표시되지 않습니다

  1. iOS 설정에서 HydroGuard의 위치 권한을「App을 사용하는 동안」으로 허용합니다.
  2. App으로 돌아가 현재 위치 또는 새로고침을 다시 실행합니다.
  3. 위치를 가져올 수 없으면 시·현과 행정구역을 직접 선택합니다.
  4. 위치는 확인되지만 값이 없으면 공식 데이터가 지연되었거나 주변에 해당 시설이 없을 수 있습니다.

HydroGuard는 백그라운드에서 이동 경로를 지속적으로 추적하지 않습니다.

카메라, 사진 또는 QR 코드가 작동하지 않습니다

iOS 설정에서 HydroGuard의 카메라 및 사진 권한을 확인하세요. QR 코드는 선택한 API 설정을 기기에서 읽는 용도로만 사용됩니다. 인증 정보를 자동으로 전송하거나 공개하지 않습니다.

API 인증 정보를 삭제하는 방법

App의「API 설정」에서 WRA 인증 정보와 CWA 인증 키를 삭제하세요. 일부 보안 저장 항목은 iOS Keychain 규칙의 영향을 받으므로 App을 제거하기 전에 App 안에서 먼저 삭제하는 것이 좋습니다.

재난 제보가 정부에 직접 전송되나요?

아니요. HydroGuard는 현재 기기에 로컬 초안을 만듭니다. 사용자가 iOS 공유 시트에서 대상을 선택하고 확인한 경우에만 콘텐츠가 App 밖으로 전달됩니다. 즉각적인 위험이 있으면 119 또는 110에 연락하고 공식 공지와 현장 지시에 따르세요.
